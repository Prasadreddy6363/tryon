--------------------------------------------------------------------------------
  ❓ TROUBLESHOOTING
--------------------------------------------------------------------------------

Problem: "File not found" error when running script
Solution: Check that you entered the correct path to the image
         Paths with spaces need quotes: "C:\My Files\image.png"

Problem: Nike shirt doesn't appear in web interface
Solution: 1. Make sure script ran successfully (look for ✅ messages)
         2. Restart Flask server
         3. Hard refresh browser (Ctrl + Shift + R)
         4. Check file exists: dir VITON-HD\datasets\test\cloth\14680_00.jpg

Problem: Shirt appears distorted or misaligned in AR
Solution: 1. Click "Men's Shirt Preset" button
         2. Enable "Show Body Keypoints" to see alignment
         3. Use quick adjustment buttons
         4. Stand 3-6 feet from camera

Problem: Script shows an error
Solution: Make sure you have Python and Pillow installed:
         pip install Pillow
