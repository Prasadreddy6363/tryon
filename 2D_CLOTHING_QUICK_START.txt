  🎨 2D CLOTHING ADDITION TOOL - QUICK START
================================================================================

I've created a web-based tool to easily add 2D dresses/clothes to your dataset!

--------------------------------------------------------------------------------
  ⚡ ULTRA-QUICK START
--------------------------------------------------------------------------------

1. Start Flask server:
   cd "C:\Users\Prasad\OneDrive\Desktop\vton github\web"
   python app.py

2. Open browser:
   http://localhost:5000

3. Click the GREEN button:
   "➕ Add 2D Clothing"

4. Drag & drop your clothing images

5. Click "✨ Process & Add to Dataset"

DONE! Your clothes are now in the dataset! 🎉

--------------------------------------------------------------------------------
  📋 WHAT IT DOES
--------------------------------------------------------------------------------

✅ Automatic resizing to 768x1024 (VITON-HD standard)
✅ Background color options (white, black, gray, transparent)
✅ Auto-generates cloth masks
✅ Centers clothing on background
✅ Batch upload support (multiple files at once)
✅ Live preview before processing
✅ Smart ID assignment (auto-increments)
✅ Direct integration with VITON-HD dataset

--------------------------------------------------------------------------------
  🎯 SUPPORTED FORMATS
--------------------------------------------------------------------------------

✅ JPG/JPEG
✅ PNG
✅ WebP

Any resolution - will auto-resize!

--------------------------------------------------------------------------------
  ⚙️ PROCESSING OPTIONS
--------------------------------------------------------------------------------

TARGET SIZE:
  • 768 × 1024 (VITON-HD Standard) ← RECOMMENDED
  • 512 × 512 (Square)
  • 1024 × 1024 (High Quality)
  • Keep Original Size

BACKGROUND COLOR:
  • White ← RECOMMENDED
  • Transparent
  • Black
  • Gray

EXTRA OPTIONS:
  ☑️ Create cloth mask (recommended - ON by default)
  ☑️ Center image (recommended - ON by default)
  📝 Filename prefix (optional - e.g., "dress", "nike")

--------------------------------------------------------------------------------
  📂 WHERE FILES GO
--------------------------------------------------------------------------------

After processing, your clothes are saved to:

  VITON-HD/datasets/test/cloth/14680_00.jpg       ← Clothing image
  VITON-HD/datasets/test/cloth-mask/14680_00.jpg  ← Mask file

ID numbers auto-increment: 14680, 14681, 14682...

--------------------------------------------------------------------------------
  🔄 AFTER ADDING CLOTHES
--------------------------------------------------------------------------------

To see your new clothes:

1. RESTART Flask server:
   Press Ctrl+C (in server terminal)
   Then: python app.py

2. REFRESH browser:
   Press Ctrl + Shift + R (hard refresh)

3. Your new clothes will appear:
   • In main clothing selection (scroll to bottom)
   • In AR Try-On clothing panel
   • Available for AI recommendations

--------------------------------------------------------------------------------
  🛠️ TROUBLESHOOTING
--------------------------------------------------------------------------------

PROBLEM: Clothes don't appear after adding
SOLUTION:
  1. Verify file exists:
     dir "VITON-HD\datasets\test\cloth\14680_00.jpg"
  2. Restart Flask server (Ctrl+C, then python app.py)
  3. Hard refresh browser (Ctrl + Shift + R)

PROBLEM: "No files uploaded" error
SOLUTION:
  • Check file format (JPG, PNG, WebP only)
  • Try selecting files again
  • Make sure files aren't corrupted

PROBLEM: Processing takes too long
SOLUTION:
  • Process fewer files at once (5-10)
  • Reduce image size before upload
  • Close other browser tabs

PROBLEM: Images look distorted
SOLUTION:
  • Use "Center image" option (ON by default)
  • Choose 768×1024 target size
  • Use good quality source images

--------------------------------------------------------------------------------
  💡 PRO TIPS
--------------------------------------------------------------------------------

✓ Use white background for best results
✓ Keep source images high quality (at least 512x512)
✓ Remove backgrounds before uploading (optional but better)
✓ Use flat lay or mannequin photography
✓ Process 5-10 items at a time for optimal speed
✓ Test new clothes in AR Try-On immediately
✓ Backup dataset before bulk additions
✓ Use filename prefix to organize by type

--------------------------------------------------------------------------------
  🎯 BEST IMAGES FOR UPLOAD
--------------------------------------------------------------------------------

GOOD ✅:
  • High resolution
  • Clean white background
  • Flat lay photography
  • Mannequin/ghost mannequin
  • Product photos
  • Good lighting

AVOID ❌:
  • Person wearing clothing
  • Busy backgrounds
  • Dark/underexposed
  • Extremely wrinkled
  • Very low resolution
  • Blurry images
