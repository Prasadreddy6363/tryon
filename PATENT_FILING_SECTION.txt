5. IMAGE PROCESSING PIPELINE:
------------------------------

Preprocessing Steps:
1. Image Loading: Read JPEG/PNG files using PIL
2. Format Validation: Check dimensions (min 512x512, max 4096x4096)
3. Resize: Scale to 1024x768 maintaining aspect ratio
4. Background Removal: Apply U2-Net or Rembg for segmentation
5. Normalization: Convert pixel values to [-1, 1] range
6. Color Space: Ensure RGB format (convert if needed)

Pose Detection Process:
1. MediaPipe Initialization: Load pose estimation model
2. Landmark Detection: Extract 33 body keypoints with confidence scores
3. Keypoint Filtering: Remove low-confidence detections (<0.5)
4. Coordinate Normalization: Convert to image coordinate system
5. JSON Export: Save keypoints in VITON-HD compatible format

VITON-HD Inference:
1. Model Loading: Load pre-trained checkpoint (mtviton.pth)
2. Input Preparation: Prepare person image, garment image, pose keypoints
3. Segmentation Generation: Predict body part masks
4. Geometric Matching: Warp garment to body shape
5. Appearance Flow: Estimate pixel-wise correspondence
6. Try-On Synthesis: Generate final blended result
7. GPU Acceleration: Utilize CUDA/DirectML for fast processing

Post-Processing Enhancement:
1. Sharpness Enhancement: Apply unsharp masking (radius=2, amount=1.5)
2. Contrast Adjustment: Histogram equalization (factor=1.2)
3. Artifact Removal: Bilateral filtering for noise reduction
4. Edge Smoothing: Gaussian blur on garment boundaries
5. Quality Optimization: Save as JPEG with 95% quality
6. Metadata Embedding: Add processing timestamp and parameters


6. REAL-TIME AR PROCESSING:
----------------------------

Camera Initialization:
• WebRTC getUserMedia API for browser camera access
• Resolution: 640x480 (default) or 1280x720 (high quality)
• Frame Rate: 30 FPS target
• Constraints: {video: {width: 640, height: 480, facingMode: "user"}}

Pose Tracking Pipeline:
1. Frame Capture: Extract video frame from camera stream (33ms interval)
2. MediaPipe Processing: Detect 33 body landmarks (15-20ms)
3. Kalman Filtering: Smooth landmark positions (2-3ms)
4. Shoulder Detection: Identify shoulder keypoints (11, 12)
5. Torso Calculation: Compute torso dimensions and orientation
6. Garment Scaling: Resize garment to match body proportions (5ms)
7. Perspective Transform: Apply homography for 3D appearance (8ms)
8. Lighting Adjustment: Match garment brightness to scene (3ms)
9. Shadow Generation: Create realistic shadows (5ms)
10. Composite Rendering: Overlay garment on video frame (5ms)
11. Canvas Display: Render to HTML5 canvas element (3ms)
Total Latency: ~70-80ms per frame (12-14 FPS effective)

Kalman Filter Configuration:
• State Vector: [x, y, vx, vy] for each landmark
• Measurement: [x, y] from MediaPipe detection
• Process Noise: Q = 0.01 (low for smooth tracking)
• Measurement Noise: R = 0.1 (moderate for stability)
• Prediction: Estimate next position based on velocity
• Update: Correct prediction with new measurement

Perspective Transformation:
• Method: Homography matrix calculation using cv2.findHomography()
• Source Points: Garment corner coordinates
• Destination Points: Body region corners (shoulder, waist)
• Transformation: cv2.warpPerspective() for realistic warping
• Interpolation: Bilinear for smooth appearance
